# 문자열 덧셈 계산기

# 구현 기능 

1. 문자열 입/출력
    - Input : 모든 입력을 받기
    - Output: 모든 출력을 관리

2. 문자열을 기본 구분자,커스텀 구분자에 따라 분리
    - Separator: 기본 구분자와 커스텀 구분자 관리
    - InputValidator: 입력 받은 문자열에 대해 여러가지 검증 진행
    
3. 분리한 숫자들의 합 계산
    - Calculator : 실제 계산과 실행 총괄

# 구조 

- IO
    - Input
    - Output

- domain
    - Calculator
    - InputValidator
    - Separator

# 동작 과정
사용자의 입력 -> 커스텀 구분자 정의 확인 -> 구분자에 따라 문자열을 분리하여 저장
-> 분리된 문자열들에 대해 검사, 예외 판별 -> 예외가 없다면 덧셈 계산 진행 -> 출력

# 정의한 예외 상황
    1. 커스텀 구분자가 1글자가 아닌 경우 (ex: "//;;\n2;;3" or "//\n234")
    2. 구분자가 연속해서 나오는 경우 (ex: "1,,2" or "//;\n2;;3")
    3. 기본 구분자나 커스텀 구분자 이외의 문자가 포함된 경우 (ex: "2/3:4")

# 추가 고려사항
    1. 빈 문자열 입력 시 결과가 0
